# Selected Preview Context

Use selected context as a precise pointer to the user's intent.

Selection may provide composition id, frame, element id, label, type, source hint, and bounding box in percent coordinates. It is strong evidence about "what the user means", but it is not sufficient proof of where to edit. Pair it with source inspection before changing code.

When confidence is low, say what is known from the selection and inspect nearby composition files before editing.
