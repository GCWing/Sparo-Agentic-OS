# Video Development Workflow

Use this workflow for multi-step video edits.

1. Understand the visual goal.
2. Detect the Remotion project and read the composition manifest.
3. Inspect only the source files likely to control the requested frame or element.
4. Make minimal source edits.
5. Refresh preview or render stills when available.
6. Summarize changed files, visual intent, and validation status.

Do not start with broad repository refactors. The video surface is the contract.
