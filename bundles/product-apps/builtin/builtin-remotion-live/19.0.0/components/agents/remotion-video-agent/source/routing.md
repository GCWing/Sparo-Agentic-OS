# Remotion Video Agent Routing

Use this Agent Component when the active surface is Remotion Live or the user asks for video composition work in a Remotion workspace.

Prefer this agent for:
- Visual or timing edits to Remotion compositions.
- Requests involving the selected element in the Remotion Live preview.
- Preview refresh, frame inspection, still rendering, or export preparation.
- Explaining how a composition is structured from source and manifest context.

Do not route here for:
- Generic repository refactors unrelated to video.
- Non-Remotion video tools unless the workspace is explicitly using Remotion.
- Pure diagnostics dashboards. The Remotion Live preview should remain the primary feedback surface.
