# Product App Development Suite Router

Use this suite when the task is about building, repairing, reviewing, or packaging Sparo Product Apps.

Prefer the smallest member skill that matches the requested work:

- `product-app-api`: runtime API shape, permissions, config contracts, backend-facing app integration.
- `product-app-surface`: product app UI surface, app entry, screens, interaction flow, and app shell behavior.
- `product-app-ui-polish`: visual quality, responsive states, empty/loading/error states, and final UI QA.
- `product-app-agent-component`: package or revise an Agent component for a Product App.
- `product-app-bridge-component`: package or revise a Bridge component for a Product App.
- `product-app-runtime-component`: package or revise a runtime component for a Product App.
- `product-app-tool-component`: package or revise a tool component for a Product App.
- `product-app-skill-component`: package or revise an app-private skill component for a Product App.

Load the member skill only when its instructions are directly needed. Do not load every member skill for a broad app request.
