# Presentation Workflow Suite Router

Use this suite for presentation strategy, deck design, visual review, and coordinated slide-generation workflows.

Prefer:

- `presentation-director` for PPT Live's minimal-input, whole-manuscript, Design Case, ordered visual production, whole-deck review, and systemic-revision workflow.
- `ppt-design` for deck structure, slide visual systems, style presets, critique, polish, and design QA.
- `lengyi-ppt-agent-team` when the task needs the dedicated multi-agent presentation workflow.

Use `pptx` from the Office Documents suite only when the task is specifically about manipulating a PowerPoint file artifact.
